# PopMastery

**Learn. Play. Master.**

A global learning hub built around short, satisfying skill games. The first version includes Typing Rush, Memory Flip, Math Sprint and Focus Hunt.

## Deploy

This is a static site and can be deployed free on Cloudflare Pages, GitHub Pages, Netlify or Vercel.

### Cloudflare Pages

1. Open Cloudflare Dashboard → Workers & Pages.
2. Create application → Pages → Connect to Git.
3. Select `codingbotlab/popmastery`.
4. Framework preset: **None**.
5. Build command: leave empty.
6. Build output directory: `/` (the repository root).
7. Deploy.

The resulting `*.pages.dev` address can later be replaced with a custom domain.
